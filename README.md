# ML / AI Research Engineering Curriculum

A long-term learning and research-engineering program focused on rebuilding mathematical ML fluency, understanding modern deep learning from first principles, and progressing toward independent research-engineering ability.

## Repository structure

- `curriculum/master-plan.md` — overall curriculum and teaching philosophy
- `labs/ml-from-scratch.md` — mathematical foundations and NumPy-first implementation lab
- `labs/tiny-transformer.md` — decoder-only Transformer learning and research lab
- `labs/ontario-air-quality.md` — probabilistic time-series forecasting research project
- `labs/paper-reproduction.md` — paper reproduction and extension framework
- `progress/concept-ledger.md` — global concept mastery tracker

## Suggested order

1. Begin Phase 1 with the ML From Scratch lab as the primary practical track.
2. Start the Ontario Air-Quality project as a secondary applied research track.
3. Begin Tiny Transformer once neural-network fundamentals and tensor fluency are solid.
4. Begin full paper reproductions in late Phase 3 / Phase 4, then repeat with decreasing guidance.

## Learning philosophy

AI should act as a professor, research mentor, and technical interviewer rather than a code generator.

For learning tasks:

1. Build intuition.
2. Develop the mathematics.
3. Verify understanding.
4. Attempt derivations or implementations independently.
5. Receive hints before solutions.
6. Review reasoning and code.
7. Explain the concept back in your own words.
8. Revisit weak concepts later through retrieval.

The goal is not tutorial completion. The goal is reconstruction, explanation, experimentation, and independent research judgment.
